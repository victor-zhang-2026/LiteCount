## 变更 / Changes

- 展开列表收至约五条事项的高度；更多事项可滚动。编辑器保留完整高度。
- 倒计时与事项文字留出更多距离，信息块颜色跟随事项 Icon。
- 移除行内编辑、删除图标；双击事项编辑，右键菜单仍可编辑和删除。
- 图标选择区改为铺满宽度的七列网格，并减少进入编辑器时的误选。

- The list panel fits about five items and scrolls for more, while the editor keeps its full height.
- Countdown badges have more space and follow each item's icon color.
- Double-click an item to edit; Edit and Delete remain in the context menu.
- The seven-column icon picker fills the panel width and guards against accidental selection on entry.
