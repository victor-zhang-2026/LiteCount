## 变更 / Changes

- 修复 1.0.1 的回归缺陷：未悬停时长事项名称全文溢出、遮挡倒计时列；现在文本严格裁剪在名称区域内，悬停时往返滚动显示完整内容。
  Fixed a 1.0.1 regression: unhovered long names overlapped the countdown column. Text is now strictly clipped to its area and ping-pong scrolls on hover.

其余功能与 1.0.1 相同。Other features are unchanged from 1.0.1.
